# 성적 관리 프로그램

## 무엇을 하나요 (What)
성적 CSV 파일을 읽어 0~100점인 (이름, 점수)만 골라 내고, 잘못된 줄은 줄 번호·이유와 함께 따로 모읍니다.

## 왜 만들었나요 (Why)
실제 성적 파일에는 점수가 빈 줄, 0~100 밖의 점수(105, -5), 숫자 대신 글자가 적힌 줄(결석), 칸이 3개인 줄, 이름 안에 쉼표가 든 줄이 섞여 있어서, 그대로 읽으면 프로그램이 멈추거나 틀린 점수가 그대로 들어갑니다.
그래서 잘못된 줄은 조용히 버리지 않고 줄 번호와 이유를 함께 남겨, 어떤 줄이 왜 빠졌는지 사람이 확인할 수 있게 만들었습니다.
테스트를 붙인 이유는, 처음 만든 테스트 11건이 모두 통과했는데도 이름이 빈 줄을 처리하는 코드(55-56번 줄)는 한 번도 실행되지 않았다는 것을 커버리지 측정으로 알게 되었기 때문입니다.

## 어떻게 쓰나요 (How)
설치 (처음 1번)
```
python -m pip install pytest pytest-cov
```
실행
```
python load_scores.py scores.csv
```

## 어떻게 테스트하나요
```
python -m pytest
python -m pytest --cov=load_scores --cov-report=term-missing
```
통과 화면
```
load_scores.py      45      9    80%   77-86
12 passed
```

## 파일 구성
| 파일 | 하는 일 |
|---|---|
| load_scores.py | CSV를 읽어 (kept, skipped) 2개를 돌려주는 함수 |
| scores.csv | 예시 입력 파일 (정상 5줄 + 잘못된 줄 5줄) |
| test_load_scores.py | 테스트 함수 7개 (12번 실행) |
